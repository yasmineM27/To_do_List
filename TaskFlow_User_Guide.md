## Getting Started

### Registration and Login

1. Navigate to the TaskFlow home page.
2. Click on "Get Started" or "Register" to create a new account.
3. Fill in the registration form with your desired username and password.
4. After successful registration, log in with your credentials.

### First Steps

Once logged in, you'll be directed to the dashboard. From here, you can:
- Create your first Todo List
- Add tasks to your list
- Create tags to categorize tasks
- View your upcoming tasks

## Dashboard Overview

The dashboard provides a quick overview of your productivity:

### Stats Cards

- **Total Tasks**: Number of tasks in all your lists
- **Completed**: Number of completed tasks and completion rate
- **In Progress**: Number of tasks not yet completed
- **Overdue**: Number of tasks past their due date

### Upcoming Tasks

Shows tasks with upcoming due dates, ordered by proximity. This helps you focus on what needs attention in the near future.

### Recent Activity

Displays your most recent task additions and completions, giving you a sense of progress.

### Quick Access

Provides shortcuts to:
- Create a new list
- View today's tasks
- Check overdue tasks
- Create a new tag

## Todo Lists

Todo Lists help you organize tasks into logical groups.

### Creating a List

1. Click "New List" on the dashboard or "Create Todo List" on the lists page
2. Enter a title and optional description for your list
3. Click "Save" to create the list

### Managing Lists

From the lists page, you can:
- View all your lists and their progress
- Edit list details (title, description)
- Delete lists you no longer need
- Add tasks to specific lists

## Tasks Management

Tasks are the core component of TaskFlow.

### Creating Tasks

1. Navigate to a specific list or use the "Add Task" button
2. Fill in the task details:
   - Title (required)
   - Description (optional)
   - Due date (optional)
   - Priority (Low, Medium, High)
   - Tags (optional)
3. Click "Save" to create the task

### Task Actions

For each task, you can:
- Mark as complete/incomplete
- Edit task details
- Delete the task
- View task details

### Task Details

The task detail page shows:
- Title and description
- Status (Complete/Incomplete)
- Due date and whether it's overdue
- Priority level
- Associated tags
- Completion date (if completed)

## Tags and Categorization

Tags help you categorize tasks across different lists.

### Creating Tags

1. Navigate to the Tags section
2. Click "New Tag"
3. Enter a name and select a color
4. Click "Save"

### Using Tags

- Add tags when creating or editing tasks
- Click on a tag to view all tasks with that tag
- Use tags to create a cross-list organization system

## Filtering and Searching

TaskFlow provides several ways to find and focus on specific tasks:

### Filters

- **Today**: Shows tasks due today
- **Overdue**: Shows tasks past their due date
- **This Week**: Shows tasks due in the next 7 days
- **By Tag**: Shows tasks with a specific tag

### Search

Use the search bar in the top navigation to find tasks by title or description.

## User Profile

The profile page shows:
- Your account information
- Statistics about your TaskFlow usage
- Option to log out

## Tips for Productivity

- Create separate lists for different areas of your life (work, personal, etc.)
- Use tags to categorize tasks across lists (urgent, waiting, etc.)
- Set due dates for time-sensitive tasks
- Check your dashboard daily to stay on top of tasks
- Use priorities to distinguish between important and less critical tasks
